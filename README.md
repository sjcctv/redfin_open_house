# 🏡 AI-Powered Open House Finder

### From a Weekend Frustration to a Full-Stack AI-Driven Solution

Weekends are my time to explore — especially visiting open houses to better understand neighborhoods and the local housing market.

But the process quickly became frustrating. I was jumping between multiple websites, manually comparing:
- Home prices
- Square footage
- Home types
- Distance between listings

All just to decide which houses were actually worth visiting.

So I turned the problem into a product.

---

## 🚀 What I Built
A full-stack web app that:
- **Scrapes open house listings automatically**
- **Calculates distances** between properties and my home
- **Aggregates key details** like price, size, and home type
- **Displays everything in a simple, clean dashboard**

The goal was simple: *find nearby open houses worth visiting in minutes, not hours*.

---

## 🤖 How AI Accelerated Everything
What would normally take me 3× longer was completed in just a few hours — thanks to AI.

ChatGPT helped me:
- Generate boilerplate code
- Debug faster
- Improve UI decisions
- Speed up experimentation and iteration

**Total cost? $0.** Free hosting + free AI tools.

---

## 💡 Why This Matters
This mini-weekend project reminded me of something important:

> **AI is dramatically lowering the barrier to creation.**

Instead of being blocked by tedious setup or slow troubleshooting, I could focus on:
- Product thinking
- User experience
- Fast iteration
- Actual problem‑solving

A small frustration turned into a full working solution — and that feeling of curiosity + ownership was the best part.
